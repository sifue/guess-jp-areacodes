# データ仕様

## 収録元と精度

`JP_AREACODES.md` を入力として59件を収録する。`code` は文字列（先頭0を保持）、`prefectures` は都道府県名配列、`hint` は覚え方文字列。47都道府県を含む。

「先頭2〜3桁のパターン」と「正式な市外局番」を区別する。たとえば012は複数の正式市外局番の共通先頭桁。都道府県配列は元資料の記載を保持する。複数県の行を代表県一つに縮約しない。単一県の行も厳密な利用区域の網羅や排他性を保証しない。

公式参考情報：[総務省「市外局番の一覧」](https://www.soumu.go.jp/main_sosiki/joho_tsusin/top/tel_number/shigai_list.html)。2026-09-06に参照を試みたが、本文の直接取得に失敗。検索結果では令和8年3月1日現在の一覧の存在を確認したが、PDF・Word内容の全件照合は行っていない。最新公式情報で検証済みのデータという表示はしない。

## 更新

1. `JP_AREACODES.md` の対応県・覚え方を更新する。公式番号表と照合する場合は、番号区画に含まれる全都道府県を確認する。
2. `npm run data:generate` でJSONと公開用原本コピーを同期する。
3. `npm run format`、`npm test`、`npm run test:e2e`、`npm run build` を実行する。
4. 件数が変わる場合はテスト、README、説明文の固定件数も合わせて更新する。
5. セマンティックバージョニングで版を更新し、変更日・根拠資料・変更内容を本書または変更履歴に追記する。

正式市外局番全件への拡張には、2〜5桁の正式番号データと県境をまたぐ利用区域の検証、問題表記の再設計が必要。

ユーザーの依頼で、トップの全国図の直下に北海道011〜016系の専用図を追加。札幌を起点とした渦巻き状の番号順を点線矢印で示す。先頭3桁の地域ラベルと正式な市外局番の都市例を分ける。番号例はNTT東日本「単位料金区域別市外局番等一覧表（01）」の札幌・千歳・岩見沢・小樽・函館・室蘭・苫小牧・帯広・釧路・網走・旭川・稚内MAを確認（2026-09-06）。

出典：https://www.ntt-east.co.jp/info-st/mutial/suburbs/numlist/pdf/ma_area1.pdf

図版は本プロジェクトの自作SVG（MIT）。図の輪郭とラベルは位置関係の模式化で、境界や番号帯の連続性を保証しない。0120など地理的番号ではない番号は対象外と明記。小画面では790pxの図を横スクロールし、同じ内容を文字の一覧でも提供する。全暗記モードおよび出題データは変更しない。
